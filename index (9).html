Offline play (no internet): Hotspot mode
  1. Host: turn on the phone/PC Wi-Fi hotspot, or put everyone on the same Wi-Fi.
  2. Host runs npm start on a PC (or Termux on Android) in the game folder.
  3. Host finds its IP (Windows ipconfig, Android: Wi-Fi details) e.g. 192.168.43.1.
  4. Every phone opens http://<host-ip>:3000, then Create or Join a room.
Browsers cannot do direct phone-to-phone Bluetooth, so the hotspot gives the same offline result using this same server.
