Night Drive 3D 🚗

Welcome to Night Drive 3D!

A 3D driving game project featuring cars, racing, stunts, and multiplayer development.

Features

- 3D driving and racing
- Car selection and upgrades
- Coins, diamonds, and nitro
- Multiplayer and player accounts (when configured)
- Mobile-friendly controls

Project Files

- "index.html" — Game interface and client-side game
- "server.js" — Server functionality
- "package.json" — Server dependencies and scripts
